Dados do responsável pela conta. Este user poderá adicionar novos users para a conta.
Nome Completo, CPF, Endereço, Email, Senha, Avatar, Dados de Pagamento
Interface UserAdmin {

  name: string;
  role: string;
  email: string;
  avatar: string;
  password: string;
  address: Address;
  paymentInfo: PaymentInfo;
}

Criar Produtos:
/api/products/add (post)
O admin pode criar produtos, que terão um nome, label e steps. Os steps são os subprodutos necessários para a conclusão, um array com id, nome, duração e ordem. A soma dos dias nos steps montará o tempo total deste produto.
Interface Product {
  id: number;
  value: string;
  label: string;
  steps: ProductStep[];
  idPosition?: number;
}

interface ProductStep {
  id: number;
  name: string;
  days: number;
  order: number;
}

interface Product[]

Lista de comentários:
/api/project/:id/comments (get)
serão separados por projeto, com a etapa referente ao comentário (stepId) Caso stepId === null o comentário será referente ao projeto e deverá ser exibido no final. Será chamado quando os detalhes de um projeto forem abertos.
Interface Comments {
  id: number;
  projectId: number;
  stepId: number;
  userId: number;
  userName: string;
  createdAt: string;
  text: string[];
}

Lista de projetos:

Interface:

  product: string;

Detalhes do projeto:
/api/project/:id (get)
endpoint listará todos os projetos ativos com steps e address. Comments serão carregados separadamente, pois podem ser muitos e tornariam o retorno deste endpoint lento.
Interface:
{
  projectName: string;
  clientName: string;
  clientAddress: {
    cep: string;
    logradouro: string;
    numero: string;
    bairro: string;
    complemento?: string;
    cidade: string;
    estado: string;
  };
  obraAddress: {
    cep: string;
    logradouro: string;
    numero: string;
    bairro: string;
    complemento?: string;
    cidade: string;
    estado: string;
  };
  product: string;
  startDate: string;
  status: projectStatus; ("planned" | "in_progress" | "completed");
  steps: {
	  stepId: number;
	  status: StepStatus;
	  actualStartDate?: string;
	  actualEndDate?: string;
	  plannedStartDate: string;
	  plannedEndDate: string;
	}
}
